# Выбор LLM для осознанного vibe-кодинга

## Главный принцип

**LLM призвана сокращать время работы.** Бесплатные или дешёвые модели заставят вас переделывать по несколько раз.

## Рекомендуемые инструменты

**Для работы рекомендуем (с учётом обновлений на май 2026):**
1. **Claude Pro (с Claude Code)** — $20/мес
2. **ChatGPT Plus / Pro (с Codex)** — от $20/мес

**Почему платные инструменты:**
- Слабые модели генерируют код, который придётся переделывать
- $20 за подписку окупаются в первый же день работы

## Платные подписки (рекомендуем)

### Claude Pro — $20/мес

**Цены**: https://claude.com/pricing

### Важно
В апреле 2026 у Claude были публичные кейсы внезапных блокировок и ложных срабатываний. Если используете Claude как основной инструмент для работы, лучше не завязывать процесс только на один аккаунт и держать запасной вариант: ChatGPT, OpenRouter или API-доступ через другой провайдер.

#### Что это
AI-ассистент от Anthropic. Подписка Pro/Max включает доступ к Claude Code (CLI + IDE-расширения VS Code/JetBrains + веб claude.ai/code).

#### Цены (на апрель 2026)
- **Pro**: $20/мес (месячная оплата) или ~$200/год при годовой
- **Max 5x**: от $100/мес (5x больше лимитов чем Pro)
- **Max 20x**: $200/мес (20x больше лимитов)

#### Лимиты (Pro)
- ~45 сообщений каждые 5 часов в Claude.ai
- Модели: **Claude Sonnet 4.6**, **Opus 4.7**, **Haiku 4.5**
- На Max-планах — расширенный контекст до 1M токенов для Sonnet/Opus
- Приоритет при высокой нагрузке

#### Использование

**IDE (VS Code)**:
```
1. Установить расширение Claude
2. Авторизоваться
3. Использовать через sidebar
```

#### Плюсы
- Лучшая поддержка MCP
- Проверенное качество
- Простой интерфейс

#### Минусы
- Лимиты на бесплатном плане очень низкие
- Max планы дорогие ($100-200)
- Бывают ложные блокировки и задержки с апелляциями

### OpenRouter — $10 один раз (для доступа к бесплатным лимитам)

**Сайт**: https://openrouter.ai  
**Цены**: https://openrouter.ai/pricing  

#### Что это
Агрегатор API для доступа к 290+ моделям через один ключ.

#### Цены
- **Free**: $0 (50 запросов/день на :free модели)
- **С $10**: 1000 запросов/день на :free модели
- **Pay-as-you-go**: платные модели по ценам провайдеров

**Важно**: $10 покупаются один раз, не сгорают, остаются на балансе.

#### Как открыть 1000 запросов/день

**Официальная документация**: https://openrouter.ai/docs/faq

Из документации:
> "If you have purchased at least $10 credits, your free model rate limit will be 1000 requests per day. Otherwise, you will be rate limited to 50 free model API requests per day."

**Инструкция**:
```
1. Зарегистрироваться: https://openrouter.ai
2. Перейти в Credits: https://openrouter.ai/credits
3. Купить минимум $10 кредитов
4. Лимиты автоматически повысятся до 1000/день
```

**Проверка лимитов**:
```bash
# API запрос
curl https://openrouter.ai/api/v1/key \
  -H "Authorization: Bearer YOUR_API_KEY"

# Ответ покажет:
# - limit: текущий дневной лимит
# - usage: использовано сегодня
# - is_free_tier: true/false
```

**Проверка в веб-интерфейсе**:
```
1. Открыть https://openrouter.ai/settings/limits
2. Увидите: "Daily free model limit: 1000 requests"
```

#### Лимиты
**Без покупки** ($0):
- 50 запросов/день
- 20 запросов/минуту

**С покупкой $10+**:
- 1000 запросов/день
- 20 запросов/минуту

#### Бесплатные модели для кода
- `qwen/qwen3-coder:free` — лучшая для кода
- `deepseek/deepseek-r1:free` — для reasoning
- `meta-llama/llama-3.3-70b:free`

#### Плюсы
- $10 один раз (не подписка)
- 1000 free запросов/день
- Доступ к 290+ моделям
- Кредиты можно использовать для платных моделей

#### Минусы
- Нужно работать с API
- Free модели медленнее в пик нагрузки
- Не для новичков
